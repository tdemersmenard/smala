# Assets de marque — Smala Vans

Dépose ici les fichiers officiels fournis par le client. Le code les référence
automatiquement avec un repli élégant si un fichier est absent.

Fichiers attendus (noms exacts) :

- `logo_smala.svg` (idéal) ou `logo_smala.png` / `logo_smala.jpg` — le wordmark / logo
- `banniere.jpg` — la bannière officielle (motif topographique)
- `og.jpg` — image de partage réseaux sociaux, 1200 × 630 px

Tant qu'un fichier n'est pas présent, le site affiche le monogramme SVG intégré
et le motif topographique généré en code. Aucune image cassée ne s'affiche.
